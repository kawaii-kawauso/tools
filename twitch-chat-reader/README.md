# Twitch Chat Reader

Twitchの配信ページを開いている間、そのチャンネルのコメントをChromeの読み上げ機能（`chrome.tts`）で読み上げるChrome拡張。コメントは画面からではなく、ログイン不要のTwitch公式チャット（IRC over WebSocket）から受け取る。

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパーモード」をONにする
2. 「パッケージ化されていない拡張機能を読み込む」で、このディレクトリを選ぶ
3. 拡張機能のアイコンから「試しに読む」を押し、声が出ることを確かめる

## 棒読みちゃんで読ませる

1. 棒読みちゃんを起動し、HTTP連携のポート（既定は50080）を確かめる
2. 拡張機能の設定画面で「読み上げに使う」を「棒読みちゃん」にする
3. 「試しに読む」を押し、棒読みちゃんが読めばOK。接続できないときは設定画面に案内が出る

棒読みちゃんには本文だけを `http://localhost:<ポート>/Talk?text=...` で送る。声・速さ・音量は棒読みちゃん側の設定で決まり、待ち行列も棒読みちゃんが持つ（この拡張の「読み待ちは5件まで」は効かない）。ショートカットの停止とOFFでは `/Clear` と `/Skip` を送る。

## ショートカット

ゲームなど別のアプリを操作中でも効く（Chromeが起動している間）。`chrome://extensions/shortcuts` で変更できる。

| キー | 動作 |
|---|---|
| Ctrl+Shift+9 | 読み上げのON/OFFを切り替え、「読み上げオン/オフ」と読み上げて知らせる。OFFにすると読んでいる途中のコメントと待ちも止める |
| Ctrl+Shift+8 | 読んでいるコメントと待ちを止める（ONのまま） |

## 設定（拡張機能のアイコンから開く）

| 項目 | 既定値 | 内容 |
|---|---|---|
| 読み上げる | ON | OFFでもチャット接続は保ち、読み上げだけ止める |
| 名前も読む | ON | 「名前、本文」の形で読む |
| 「!」で始まるコマンドを読まない | ON | `!uptime` などのbot向けコマンドを読まない |
| 配信者本人のコメントを読まない | ON | 視聴者として配信者の発言も聞きたいときはOFFにする |
| 読み上げに使う | Chromeの音声 | 「棒読みちゃん」にすると棒読みちゃんに送る |
| 棒読みちゃんのHTTP連携ポート | 50080 | 棒読みちゃんを選んだときだけ表示 |
| 声 | 既定 | 日本語の声だけを一覧に出す。Chromeの音声のときだけ表示 |
| 速さ / 音量 | 1.2倍 / 100% | Chromeの音声のときだけ表示 |
| 最大文字数 | 60 | 5〜500。超えた分は切り詰めて「、以下略」と読む |
| 読まないユーザー | nightbot, streamelements, moobot | ログイン名か表示名を1行に1人 |
| 読まない言葉 | なし | 1行に1つ。含むコメントは丸ごと読まない |
| 読むチャンネル | なし（全部） | 1行に1つ。書いたチャンネルのページでだけ接続する |

## 読み上げ前の整形

- URLは「URL」、`www` は「わら」、`8888` は「パチパチ」と読む
- 同じ文字が4回以上続いたら3回に縮める（「ああああああ」→「あああ」）
- エモート、絵文字、返信の先頭の `@名前`、`<` `>` と制御文字を消す
- 同じ人のコメントは5秒に1件まで。直前に読んだのと同じ文は読まない

## 制約

- Chromeの音声では、読み待ちは5件まで。超えたら古いものから捨て、新しいコメントを読む
- Twitchのタブを複数開くと、接続も複数になり同じコメントを重複して読む
- 拡張機能を更新・再読み込みしたら、Twitchのページも再読み込みする（古いページは接続を閉じて止まる）
- 拡張機能の処理は、毎秒50件のコメントでもCPU時間が10秒あたり約20ms、メモリは約2MBに収まる。音声合成そのものの負荷は、選んだ声（OSの声かネットワーク経由の声か）によって変わり、未計測

ロジックの詳細は [docs/logic.md](docs/logic.md)。
