# Twitch Chat Reader

Twitchの配信ページを開いている間、そのチャンネルのコメントをChromeの読み上げ機能（`chrome.tts`）で読み上げるChrome拡張。コメントは画面からではなく、ログイン不要のTwitch公式チャット（IRC over WebSocket）から受け取る。

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパーモード」をONにする
2. 「パッケージ化されていない拡張機能を読み込む」で、このディレクトリを選ぶ
3. 拡張機能のアイコンから「試しに読む」を押し、声が出ることを確かめる

## 設定（拡張機能のアイコンから開く）

| 項目 | 既定値 | 内容 |
|---|---|---|
| 読み上げる | ON | OFFでもチャット接続は保ち、読み上げだけ止める |
| 名前も読む | ON | 「名前、本文」の形で読む |
| 「!」で始まるコマンドを読まない | ON | `!uptime` などのbot向けコマンドを読まない |
| 声 | 既定 | 日本語の声だけを一覧に出す |
| 速さ / 音量 | 1.2倍 / 100% | |
| 最大文字数 | 60 | 超えた分は切り詰めて「、以下略」と読む |
| 読まないユーザー | nightbot, streamelements, moobot | ログイン名を1行に1人 |

## 制約

- 読み待ちが5件（`MAX_PENDING`）を超えると、新しいコメントは読まずに捨てる。読み上げより速くコメントが来たときに、遅延が際限なく伸びないようにするため
- Twitchのタブを複数開くと、接続も複数になり同じコメントを重複して読む
- 拡張機能の処理は、毎秒50件のコメントでもCPU時間が10秒あたり約23ms、メモリは約2MBに収まる。音声合成そのものの負荷は、選んだ声（OSの声かネットワーク経由の声か）によって変わり、未計測

ロジックの詳細は [docs/logic.md](docs/logic.md)。
